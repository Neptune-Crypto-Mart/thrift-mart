# thrift-mart-web

The web frontend for **Thrift Mart** — a crypto-powered marketplace on Stellar
(XLM/USDC) for selling pre-loved items at affordable prices. Fast, low-fee
transactions, escrow protection, and global reach. Declutter smart, buy
sustainably, pay with digital assets.

## Tech stack

- [Next.js](https://nextjs.org) (App Router, Turbopack)
- [React](https://react.dev)
- [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)

## Getting started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result. The
page auto-updates as you edit files under `app/`.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — run the production build

## Project structure

```
app/            # App Router pages, layouts, and global styles
public/         # Static assets
```
